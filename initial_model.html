Overview

In this ‘Initial Model and Results’ portion of the project, I plan to first run a proportional-odds cumulative-logit model on every variable, and then remove those with obvious p-value, clinical, and covariance issues that were discussed in the EDA stage. Then we will rerun our model and test the proportionality assumption, to see if we can proceed with model selection and testing under this assumption. From there, I will narrow down several candidate nested models of which I will perform LR tests and use BIC/AIC to compare them. Using BIC, AIC, and these LR tests, I will narrow down to 2 models, of which I will provide coefficient interpretaion for what I believe to be the ‘leader’ among them, and discuss problems I ran into along the way.

This model looks far cleaner than the one we started with, but still has a ways to go. We will now perform a Brant-Wald Test for proportionality on this model.

# | echo: false

# performing prop test in R

library(tidyverse)
library(MASS)
library(brant)

r_prepropXY = read_csv('./data/preprop_XY.csv')
r_prepropXY$cap_cat = ordered(r_prepropXY$cap_cat)

r_preprop_model <- polr(
    cap_cat ~ .- cap_cat,
    data = r_prepropXY,
    method = 'logistic',
    control = list(maxit = 100000)
)

brant(r_preprop_model)

From this Brant test, parallel regression holds for this model barely, and we will now proceed to testing additional models based off of this model. We will make sure to check this assumption again in the future when we have come to a final model.

Initial Issues

I also originally had model convergence issues, which was fixed by just increasing the amount of model iteratons to 100000, at which point the model converged well below that number (20000ish).

Furthermore, Python has no native method to run a Brant-Wald for proportionalty, hence I had to port my data over to R, run the same model, and perform the test before moving on.

Steps for Final Report

I have narrowed myself down to two models using AIC/BIC values and LR tests. I will perform cross validation in the next portion of the project, with HUM as the metric, and use this to decide on my final model. On this final model, I will run another Brant-Wald test, a Pearson Goodness of Fit test, and use cook’s distance to find high leverage high residual points and assess whether there is justification to remove them from the model to tighten up estimates without comprimising our research process, or whether they should remain. I will finally interpret this final model.
